## What

Ratifies **ADR-032** (R1-GAP-023 Option A): **two settings stores kept, one canonical source of truth.**

- **Canonical (sole source of truth for runtime behaviour):** the Handy-derived `AppSettings` document — `apps/desktop/src-tauri/src/settings.rs`, `tauri-plugin-store` `settings_store.json`, key `"settings"`. Audio (`selected_microphone`), the shortcut system (`bindings` + `shortcut_activation`), transcription (`selected_model`), tray, secure input, post-process and theme all read it.
- **Compatibility (UI-local persistence, never authoritative):** `soravo-config` — `<config_dir>/soravo/settings.json`, exposed by the `soravo_ipc` settings commands. Reclassified from "undecided duplicate" to "declared compatibility store with a named owner".

## Normative mirror rule

1. **Direction** — one way, canonical → compatibility. No path exists by which a compatibility value can reach the canonical store.
2. **Trigger** — only a *successful canonical write* may mirror. Never a load, read, or startup. Enforced structurally by the `MirrorCanonical` token.
3. **Conflict** — canonical always wins, unconditionally, without consulting the compatibility value.
4. **Unrepresentable values are never approximated** — `ShortcutActivation::HoldOrToggle` (the upstream default, which `hotkey.mode` has no variant for), the structured `bindings` map (textual form is Handy-owned and must not be fabricated per v6 §21), and `microphone.selected_device_index` (no canonical counterpart) are left untouched and recorded.
5. **Startup is a no-op** — `Settings::load` reconciles nothing, so no silent migration occurs.

## Implementation (smallest safe change)

`crates/config` only — the SORAVO-NEW store. Additive schema v1 -> v2 adding a defaulted `mirror: { applied, last }` provenance block; value-preserving, so a pre-v2 file provably carries `applied: 0` and an on-disk value can never be mistaken for a mirrored one across a restart. `InteractionMode` gains `as_str()` and `FromStr` (which *errors* rather than defaulting).

**Deliberately not done:** no mirror wiring to any canonical write site, no change to `settings.rs` / `soravo_ipc.rs` / any `#[tauri::command]` / any UI file / any Handy-derived source, no dependency, lockfile, workflow or manifest change, no settings migration, no settings UI redesign.

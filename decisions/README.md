# Architecture decision records

Create an ADR only for a material architectural, security, privacy, data-model, deployment, payment, authentication, platform, or inference decision. Do not use ADRs for routine implementation details.

```text
# ADR-NNN — title

Status:
Date:
Context:
Decision:
Alternatives:
Security impact:
Performance impact:
Operational impact:
Testing impact:
Rollback:
Consequences:
```
